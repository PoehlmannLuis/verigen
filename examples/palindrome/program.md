# Implement `is_palindrome(s: str) -> bool`

Return `True` if `s` is a palindrome, ignoring case, spaces, and punctuation.

The `initial.py` file has the function skeleton with an EVOLVE-BLOCK region. The
evaluator checks correctness (all 10 test cases must pass) and measures average
latency across 18,000 calls — the metric is throughput-normalized to `[0, 1]`.

Optimize for speed without breaking correctness. The initial implementation
just raises `NotImplementedError`.
